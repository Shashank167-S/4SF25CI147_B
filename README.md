# Netflix Data Analysis Using Python

## Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python and Pandas.

## Objectives
- Read and understand CSV data.
- Perform data transformation.
- Identify and handle missing values using mean imputation wherever applicable.
- Generate meaningful insights.
- Visualize data using charts.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Netflix Movies and TV Shows dataset (`netflix_titles.csv`).

## Analysis Performed
1. Dataset understanding.
2. Data cleaning and transformation.
3. Missing value handling.
4. Insight generation.
5. Data visualization.

## Conclusion
This project helped me understand data analysis using Python, handling missing values, transforming datasets, generating insights, and creating visualizations.
